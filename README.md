# مالیار (Maliiiii)

دستیار مالی شخصی فارسی — آفلاین، خصوصی و سه‌بعدی. نسخهٔ ۰.۸.۰

## وضعیت فعلی (فاز P001 تا P006)

- پروژهٔ **Flutter** با پلتفرم‌های Android و iOS (نام نمایشی «مالیار»)
- سیستم طراحی **سه‌بعدی Premium**: کارت لایه‌ای، سایهٔ عمق، سطوح شیشه‌ای،
  میکرو-انیمیشن، بدون سنگین‌کردن رندر
- تم **روشن و تاریک** + RTL + فونت **Vazirmatn** + اعداد فارسی
- امضای توسعه‌دهنده: «توسعه‌دهنده: علی بهمنی» (طلایی، ظریف و غیرمزاحم)
- داشبورد واقعی متصل به هستهٔ مالی (`FinancialLedger`): موجودی، پول آزاد واقعی،
  درآمد/هزینهٔ ماه، پس‌انداز، بدهی، امتیاز سلامت مالی و پیش‌بینی
- صفحات: خانه (داشبورد)، گزارش‌ها، وام‌ها و بدهی‌ها، تنظیمات، درباره
- **پروفایل و امنیت (P003)**: معرفی فارسی (Onboarding)، ذخیرهٔ پایدار محلی،
  قفل برنامه با PIN (هش SHA-256 با salt)، ویرایش پروفایل، واحد پول
  تومان/ریال، لحن اعلان، حالت نمایش و سلام داشبورد با نام واقعی کاربر
- **پایگاه دادهٔ محلی و Repository (P004)**: سریال‌سازی JSON همهٔ موجودیت‌ها،
  ذخیرهٔ اتمیک دفترکل (`ledger.json`)، `LedgerController.commit` و اتصال
  داشبورد به دفترکل بارگذاری‌شده — بدون هیچ عدد ثابت در UI
- **حساب‌ها / درآمد / هزینه / انتقال (P005)**: ساخت حساب با موجودی اولیه،
  ثبت درآمد و هزینه با دسته‌بندی فارسی، انتقال بین حساب‌ها بدون دوباره‌شماری،
  صفحهٔ «حساب‌ها» با موجودی واقعی و ثبت سریع از داشبورد
- **تقویم شمسی (P006)**: تقویم ۳بعدی کاملاً شمسی با نام‌های فارسی ماه/روز،
  کبیسهٔ درست، رویدادهای روزانه (درآمد/هزینه/انتقال/قسط)، نشانگر رنگی رویداد و
  وضعیت مالی هر روز
- **موتور چند-وام و اقساط (P007/P008)**: ثبت وام، برنامهٔ خودکار اقساط
  ماهانهٔ شمسی، قسط نامنظم، پرداخت جزئی/چندمرحله‌ای، تغییر سررسید، لغو و
  تسویهٔ وام
- **بودجه و تراکنش‌های تکرارشونده (P009)**: تب «بودجه» با سقف/مصرف واقعی
  و کارت پیشرفت، بودجهٔ بازه‌ای شمسی با دسته، تراکنش تکرارشونده
  (روزانه/هفتگی/ماهانه/سالانه) و ثبت خودکار سررسیدها بدون دوباره‌شماری

## اجرا

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## تست

- `dart test` برای هستهٔ Dart و `flutter test` برای ویجت‌ها
- در هر commit، analyze بدون خطا و همهٔ تست‌ها پاس شده‌اند.

## محدودیت‌های صریح این فاز

- محیط فعلی SDK اندروید و Xcode ندارد؛ ساختار پلتفرم ساخته شده اما **build واقعی
  Android/iOS ادعا نمی‌شود**.
- ثبت داده (درآمد، هزینه، حساب، وام) در فازهای بعدی به همان هستهٔ مالی متصل
  می‌شود؛ داشبورد فعلی اعداد واقعی موتور را نمایش می‌دهد.
- جزئیات در `docs/KNOWN_LIMITATIONS.md`.
