# Maliiiii

دستیار مالی شخصی فارسی، آفلاین و خصوصی.

این اولین نسخهٔ قابل‌تست پروژه است و از هستهٔ دامنه شروع می‌شود. تمام مبلغ‌ها
به‌صورت واحد صحیح کوچک نگهداری می‌شوند و محاسبات به `double` وابسته نیستند.

## اجرا

```bash
dart pub get
dart analyze
dart test
```

## قابلیت‌های پیاده‌سازی‌شده

- پول دقیق با پشتیبانی از ارز
- حساب‌های متعدد و انتقال بدون دوباره‌شماری
- درآمد و هزینهٔ دفترکل
- چند وام با اقساط نامنظم
- پرداخت ناقص و چندمرحله‌ای
- پرداخت زودهنگام با نگهداری جداگانهٔ تاریخ سررسید و پرداخت
- بدهی باقی‌مانده و پول آزاد
- بودجه و اهداف مالی
- گزارش ماهانه
- پیش‌بینی با رد دادهٔ ناکافی
- امتیاز سلامت مالی با وزن‌های مستند
- تبدیل تاریخ میلادی و شمسی
- نمایش اعداد فارسی
